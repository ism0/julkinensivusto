## Pelaaminen puhelimella

Molemmat pelit on suunniteltu toimimaan tietokoneella, tabletilla ja
puhelimella. Puhelimella vasemman reunan virtuaalinen joystick liikuttaa
hahmoa ja oikean reunan toimintopainikkeilla voi hypätä tai ampua pelistä
riippuen. Peli toimii sekä pysty- että vaakasuunnassa.
